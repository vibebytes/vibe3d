# @vibebyte/vibe3d-mcp

MCP server for building and rendering 3D scenes. Starts the local `@vibebyte/vibe3d-daemon` for you.

```bash
npx -y @vibebyte/vibe3d-mcp
```

Requires Node.js >= 22. Registry name: `io.github.vibebytes/vibe3d`.

See the project README:

- English: https://github.com/vibebytes/vibe3d/blob/main/README.md
- 中文: https://github.com/vibebytes/vibe3d/blob/main/README_CN.md
